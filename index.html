Planning only. This screen creates no keys and broadcasts no transactions. Use the CLI to create a signed invitation.

Two keys. Three actions.

01Sender and recipient exchange public keys, agree on the delay, and fund one contract output.
02Recipient signs a claim to their chosen payout address.
03After the delay, sender can sign a recovery. The first confirmed spend wins.

A recovery delay is a minimum age in blocks, not an exact wall-clock deadline. Recipient claims remain valid after recovery matures.

Reproduce and review

Run the export command before downloading. The public-parameter planner checks real curve points and compiles the same P2SH32 policy; compare its bytecode with the actual XO funding output. Use your own role keys. Funding, execution and debug-tool evidence remain pending.

npm run plan -- your-public-parameters.json
npm run test runs offline policy checks. These do not prove chain confirmation or current UTXO age.
